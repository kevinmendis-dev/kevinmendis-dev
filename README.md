👋 About Me

I'm Kevin Mendis, a Computer Science undergraduate at Informatics Institute of Technology (IIT), Sri Lanka, affiliated with the University of Westminster.

I'm interested in designing and building useful software—from backend services and APIs to full-stack web applications. I enjoy breaking problems into manageable parts, understanding how systems work, and improving through consistent practice.

🎓 Currently studying: BSc Computer Science

🧩 Primary focus: Software Engineering and Full-Stack Development

⚙️ Interested in: Backend development, REST APIs, databases, and software design

🧠 Currently exploring: Machine Learning and its practical applications

🌱 Approach: Learn the fundamentals, build, test, reflect, and improve

I aim to write software that is understandable, maintainable, and useful—not just code that works once.
